1. **근거의 존재:** 평가 질문 30건 각각 하나 이상의 기존 Chunk를 인용한다. JSONL의 인용 문구는 해당 Chunk 본문 안의 연속 문자열인지 자동 확인했다.
2. **Persona 조건:** 조건 판단 문항은 학년/입학연도/학점/성적/소득구간/수상/장애/보훈/재학 상태 중 관련 값만 제공한다. 알 수 없는 수혜 이력 등은 `unknown` 또는 추가 확인으로 남겼다.
3. **수치·날짜:** 수강편람 p.6에서 6–18학점, 최종학기 최소 3, 특정 코호트 최대 20, 직전학기 16학점+B+(3.5) 최대 21 조건을 대조했다. 일정은 공고별 학기와 마감일을 별도로 비교한다.

- **OCR/구식 화면:** 국가장학금 PDF 화면 매뉴얼, 영어졸업인증 PDF의 예시, HWP 화면/빈 양식, DOCX 내 수년 전 캡처는 검색 정답에서 제외했다. 필요한 현재 정보는 게시글 또는 보존이 더 나은 원본에서 가져온다.
- **표 최종 검수:** 푸른등대 상세 계획서 전체 표를 기계 추출했지만 103쪽 모든 수치 셀을 시각적으로 수기 대조하지는 않았다. 유형별 적격 여부를 확정하는 운영 평가 전에 관련 페이지를 추가 대조해야 한다.

- **검색 기준일:** `current`는 2026-09-16 시점의 접수 상태이지, 영구적인 최신성 표지가 아니다. 다음 실행 시 오늘 날짜를 기준으로 상태를 다시 계산해야 한다.

## 근거 검색이 일반 LLM 답변과 다른 점

일반 LLM은 기억에 남은 과거 일정이나 유사 학교 규정을 현재 세종대 정보처럼 답할 수 있다. 이 데이터셋은 적용 학기·게시일·접수 기간·상태를 Chunk에 붙여 학기와 기준일을 먼저 비교하고, 만료 자료는 현재 질의에서 제외할 수 있게 한다. 문서명·공식 URL·페이지/원문 위치와 표 구조를 함께 반환하므로 각 수치와 조건을 출처에 연결할 수 있다. Persona 평가 문항은 학생의 명시된 학년·성적·소득구간·입학연도·학적 상태를 조건표에 대조하고, 필수 정보가 없거나 공고가 충돌할 때 확답을 유보하는지 측정한다. 이는 검색 기반 개인화의 데이터/평가 준비이며, 실제 검색기·답변 시스템의 동작을 보장하거나 구현한 것은 아니다.
